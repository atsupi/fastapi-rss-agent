FastAPIで受け取った指示をAIエージェントが解釈し、RSS/Atomフィードから記事を取得。 Amazon Bedrockのモデルが、必要な情報をまとめて返すニュース要約APIです。

ニュースフィードのURLを含む指示を受け取ると、エージェントがRSS取得ツールを呼び出して記事を読み込みます。 取得した記事情報をもとに、モデルが自然な要約を生成します。

RSS / Atom 対応 ツール呼び出し 日本語の指示 単一エンドポイント

MODEL_ID 環境変数で指定
レスポンス
{"output": "..."}

クライアントは prompt または message を含むJSONを /invocations に送信します。

REQUEST · cURL 
curl -X POST "http://127.0.0.1:8000/invocations" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"https://news.yahoo.co.jp/rss/topics/top-picks.xml の最新ニュースを3件教えて"}'
エンドポイント

POST /invocations · JSON形式

入力フィールド

prompt を優先。代わりに message も指定できます。

応答形式

{"output": "エージェントの応答"}

実際に試すには

サーバーを起動し、AWS認証情報・リージョン・モデルIDを設定してください。

⚡

FastAPI + Uvicorn

HTTP APIとローカル開発サーバーを提供します。

✳

Strands Agents

モデルとRSS取得ツールをまとめ、指示に応じて処理します。

◉

Amazon Bedrock

MODEL_ID とAWS環境設定を使ってモデルを利用します。

◔

feedparser

RSS / Atomを解析し、タイトル・リンク・日時・概要を抽出します。

📦

uv

依存関係とPythonプロジェクトの実行を管理します。

✓

Ruff + pytest

CIではフォーマット・lintとテストを実行します。

環境変数を設定

モデルID、AWS認証情報、リージョンを実行環境に用意します。

MODEL_ID · AWS_DEFAULT_REGION

サーバーを起動

依存関係を同期した後、開発サーバーを実行します。

uv sync
uv run uvicorn src.app:app --host 127.0.0.1 --port 8000 --reload
ⓘ 補足：このガイドのAPI例は説明用です。実際の応答には起動中のAPIと利用可能なAWS Bedrock環境が必要です。APIハンドラーは同期実装です。
